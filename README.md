# Redux Toolkit Learning Journey

A practical learning journey to understand **Redux and Redux Toolkit (RTK)**, from fundamental concepts to advanced state management techniques in React applications.

This repository contains my learning notes, practical examples, exercises, and mini-projects while exploring Redux Toolkit.

## 🎯 Learning Objectives

- Understand Redux and centralized state management.
- Learn Redux Toolkit and its core concepts.
- Configure and manage a Redux store.
- Create and manage slices using `createSlice()`.
- Understand actions, reducers, and dispatching.
- Access and update global state using React-Redux hooks.
- Handle asynchronous operations and API integration.
- Explore RTK Query for data fetching and caching.
- Apply Redux Toolkit in real-world React and React Native applications.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- Redux Toolkit

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to a practice project

```bash
cd redux-toolkit-learning-journey/practice/counter-example
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

*Note: Each practice project may have its own dependencies and setup instructions.*
